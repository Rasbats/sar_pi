# SAR Plugin for OpenCPN

The **SAR Plugin for OpenCPN** provides Search and Rescue (SAR) pattern plotting capabilities for OpenCPN.



## Features

The plugin aims to:

1. Generate GPX/RTZ files for the main SAR search patterns.
2. Plot selected SAR patterns directly in OpenCPN.

More information in the [online manual](https://opencpn-manuals.github.io/main/sar/index.html).


## Building

The plugin uses a continuous integration workflow described in the [Alternative Workflow wiki](https://github.com/Rasbats/managed_plugins/wiki/Alternative-Workflow).

This workflow can also push updated plugin metadata files to a clone of the [OpenCPN Plugins repository](https://github.com/OpenCPN/plugins), simplifying the process of preparing pull requests against the official repository.
